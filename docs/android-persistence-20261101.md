# Android 端口与本地恢复验收

2026-11-01，北京时间。本轮端口展示与持久化实现已覆盖安装到用户连接的 Android 手机。

## 改动

- 连接卡片显示源端口、目标端口和源地址；详情补充目标 IP，IPv6 端点使用方括号。
- 保存控制器地址、连接启用状态、开关、出口选择、页面、最近 60 个图表样本、已观测转发累计和最近 100 条请求日志。每 5 秒及进入后台时保存历史，设置操作时保存设置。
- Secret 用 Android Keystore AES-GCM 加密保存并绑定控制器地址；解密失败不自动连接。断开时移除保存的 Secret。无新增依赖或第三方代码复制。
- 恢复历史时重建计数基线并插入曲线断点，关闭期间不计量；相同控制器地址或相同出口选择不重置历史，更换范围才重置。
- 所选出口没有匹配活跃连接时给出节点名称提示。

## 实机诊断

手机 Clash Meta 2.11.36 的外部控制器在正确保存 `127.0.0.1:9090` 并停止、启动后可用。`/version` 和 `/connections` 返回 HTTP 200，已观察到 10 条连接均带源端口和目标端口。

`/proxies` 显示唯一实际代理节点为 `WireGuard-android`，`Overseas` 是指向该节点的策略组。此前用户选择的是配置文件名，不能匹配连接出口。改为实际节点后，旧版实机界面已显示 4 条转发连接、下载累计 10.0 KB、上传累计 1.7 KB；同期连续 8 次快照的连接字节无增长，瞬时速率为零符合这段采样数据。

## 验证

- 离线 `assembleDebug`、`testDebugUnitTest`、`lintDebug`、`assembleDebugAndroidTest` 成功。15 项单元测试通过；Lint 0 errors、7 warnings，未关闭检查。
- 设备执行 `adb shell am instrument -w io.wiesler.android.test/io.wiesler.android.PersistenceTest`，2 项检查通过：有断点的历史和有界日志落盘恢复；Keystore 密文恢复、不同控制器地址拒绝解密、断开后不再启用。测试使用独立存储，不更改用户数据。
- 对 Wiesler 执行 force-stop 后重启，历史采样从 56 条增长至上限 60 条，日志从 51 条增长至 56 条；既有日志和非零采样仍存在，出口选择和开关保留，重启后新增控制器 HTTP 200 日志。
- 本地截图位于 `target/android-controller-check/`，含 `selected-wg.png` 和 `persistence-restarted.png`。

## 边界

首次升级无法恢复旧版仅在内存中的数据。强制终止可能丢失最近约 5 秒的未保存样本。仅前台观察，实时连接重新读取；没有实现后台采集或无限历史归档。本轮未测试手机重启、密钥失效、存储耗尽或长时间稳定性。加密 Secret 在隔离设备测试中验证；真实控制器当前无需 Secret，不代表已完成真实鉴权重连验收。
