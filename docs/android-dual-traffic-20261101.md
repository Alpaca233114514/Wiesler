## 行为

- 概览显示全局流量、海外转发流量两张下载 / 上传曲线，各自有监控开关。全局默认开启，海外转发默认关闭。
- 全局继续使用 Android TrafficStats；海外转发每秒读取一次 Mihomo `/connections`，只计算用户指定实际出口节点的稳定连接增量。
- 出口可从当前连接选择，或逐行手动填写；名称使用精确匹配。切换控制器地址清除旧出口选择，重新配置控制器或改变选择重建图表与累计。
- 连接页新增直连、海外转发、其他 / 未知筛选，并显示出口；概览有直达转发连接入口。
- 计数回退、后台、重新开启、失败或超过 5 秒的采样缺口不计算跨缺口速率。错误状态与有效零流量分开显示；旧请求不能覆盖新配置。
- 沿用前台只读观察、回环 HTTP / 远程 HTTPS、内存 Secret 等边界，没有新增依赖。

## 统计限制

“海外”是用户指定的出口集合，不自动推断地理位置。新连接首次采样仅建立基线；采样之间已结束的短连接及最后一段数据可能漏计。“已观测”累计是采样到的增量，不是完整计费量。系统全局数据与应用层转发数据口径不同，VPN 还可能重复计量，不能用两图相减计算直连流量。

两图最多保留 60 个采样位置，包含断点；控制器响应慢时不等同于一分钟。记录保留在 Activity 内存中，退出或重建后重置，无后台持续采集。
