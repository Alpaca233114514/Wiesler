# Android 图谱工作台

2026-11-02，北京时间。按桌面工作台制作原生 Kotlin / Android Views 新界面，沿用现有手机控制器和监测数据。未新增依赖，未提交或推送。

## 界面与交互

- 首次升级进入「图谱」，后续恢复上次页面。图谱默认实时模式，已启用的控制器沿用原有自动重连；未配置时显示连接入口，不填入演示连接。
- 深蓝背景、薄荷绿下载、蓝色上传、点阵画布和会话检查器与桌面统一。底部保留图谱、概览、应用、连接、诊断五个入口。
- 图谱支持节点拖动、空白平移、双指缩放、放大 / 缩小与适配。点击节点、连线或会话卡片打开底部检查器，提供概览、事件、原始 JSON，文本可选中复制。
- 搜索及全部 / TCP / UDP 筛选同时作用于图谱和列表。图谱最多绘制 6 条会话，显示绘制量 / 匹配量，选中项优先。列表初始显示 30 条，可逐批增加至 200 条。
- 冻结和回放只改变查看的快照，不停止前台采样。最近 60 个快照滚动保留；冻结引用保持原样，即使该帧已移出滚动窗口。「回到现在」显示最新快照。
- 新控件使用原生按钮、按压反馈及至少 48dp 触摸高度。系统关闭动画时不播放流量脉冲；图谱标签可省略，完整内容可在随系统字号缩放的会话列表与检查器中读取。

## 数据与生命周期

实时模式复用 `MainActivity` 的只读 `/connections` 请求，无第二个轮询器；保持已有控制器地址校验、Keystore Secret 保存、失败清空和过期请求丢弃逻辑。更换控制器或重连时清除图谱回放，避免混合不同采样范围。

速率按连接 ID、开始时间、路由和单调时钟计算；首次、计数回退、无效计数、失败恢复、前后台切换或超过 5 秒的缺口只重建基线。冻结时顶部仍显示当前控制器状态。

演示为本地确定性数据，使用文档地址与 example 域名，不生成测速请求。演示 TLS 超时是场景事件；实时模式不推断请求成功、失败或 TLS 错误。脉冲代表快照字节增量，不是单包动画。

图谱快照、筛选、选择、冻结及演示状态仅在当前 Activity 内存中保留，Activity 重建或退出后不恢复。原有流量图表、请求日志与设置的本地持久化保持原逻辑。仅前台采样。

## 实现位置

- `StudioModel.kt`：纯 Kotlin 快照与回放状态、差分和演示场景。
- `StudioGraphView.kt`：Canvas 图谱及触摸操作。
- `StudioPanel.kt`：原生工作台、筛选与检查器。
- `MainActivity.kt`：默认入口、既有采样与新页面接入。

开发前已在 GitHub 搜索 Android 图可视化实现并检查 GraphView 相关项目。本轮按仓库现有桌面视觉使用 Android 平台 API 独立实现，没有复制第三方代码或安装新依赖。
