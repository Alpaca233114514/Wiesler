# 桌面神经元图谱与工作台

当前范围仅桌面端，Android 按用户后续指示暂缓。

## 入口

桌面程序默认打开 `desktop/ui/studio.html` 的实时模式，等待用户连接控制器。图谱、运行监测（流量趋势、ICMP、请求日志）和历史诊断已融合为同一工作台，切换视图保留状态。浏览器可直接打开该 HTML 并选择演示数据，实时数据须使用 Tauri 桌面程序。旧 `index.html` 保留兼容入口。

普通窗口默认 `1040 × 808` 逻辑像素，依据用户提供的 Chrome 截图（约 `2080 × 1616` 物理像素）及本机 200% 缩放设置。图谱按画布实际宽高重新排布，节点字号保持不变。

## 交互

- 应用与目标之间显示逻辑会话，点击节点、连线或会话行查看详情。
- 节点可拖动，空白画布可平移；缩放按钮和「适配」可恢复视野。图谱禁用文本选择，检查器保留复制能力。
- 搜索和协议筛选同步更新图谱、表格及检查器。
- 冻结画面不暂停前台采集；时间条回放最近 60 个快照，「回到现在」恢复实时画面。
- 检查器提供概览、事件、原始连接 JSON；演示异常可追溯到对应的场景事件。
- 图谱最多绘制 6 条会话，计数显示绘制量 / 匹配量，所选会话优先显示；表格最多显示 200 条，支持搜索缩小范围。
- 使用无边框窗口，在应用顶栏提供最小化、最大化 / 还原和关闭按钮；顶栏空白支持系统拖动及双击最大化。原监测面板也保留同样的窗口控制。按钮使用现有 Tauri 窗口 API，只给本地 main 窗口增加对应权限。

## 数据口径

手动选择的「演示数据」全部为本地确定性场景，使用保留文档地址及 example 域名，不发起实际测试流量。场景中的 TLS 超时不是故障检测结果。

「实时连接」使用既有只读 Mihomo IPC。累计量按会话 ID 和开始时间求差；新连接、错误恢复、计数回退或超过 5 秒的缺口重新建立基线。实时数据不生成演示异常，不从连接消失推断请求失败。

每次快照有对应方向的字节增量时显示一次脉冲，线宽对应增量速率；不是逐包动画或包速率。暂未实现原始抓包、PCAP 导入、TLS 解密或 HTTP 内容检查，原始数据面板展示实际连接 JSON。动画遵循系统减少动态效果设置。

## 图谱初始版本验证

以下为融合前的图谱验收；当前版本的联调结果见[前后端融合记录](desktop-integration-20261102.md)。

- `node --test --test-isolation=none desktop/tests/ui.test.cjs desktop/tests/studio.test.cjs`：17 项通过。
- `cargo build --manifest-path desktop/Cargo.toml --locked --offline --target-dir "$env:LOCALAPPDATA/Wiesler/build"`：通过。
- Chrome 实际操作验证：节点点击关联异常事件；拖拽后节点位置改变、文本选区为空；协议筛选同步更新图谱和检查器。
- Windows 实际窗口已确认系统标题栏移除，最大化 / 还原切换及关闭退出生效。最小化操作后控制工具截图可能返回缓存画面，未据此宣称视觉验证通过。

窗口 API 用法核对了 [Tauri 官方窗口自定义文档](https://v2.tauri.app/learn/window-customization/) 和本机锁定的 Tauri 2.12.5 源码，未复制示例代码。

开发前已通过 GitHub 搜索相关网络可视化项目；本轮使用原生 SVG 和现有 Tauri IPC，没有复制第三方代码或新增依赖。
